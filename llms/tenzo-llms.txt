# Tenzo

> Tenzo is a restaurant analytics and business-intelligence platform that unifies data from point-of-sale, labor scheduling, inventory, reviews, and reservation systems into a single reporting layer across 90+ integrations. It exposes a public REST API, an OAuth 2.0 (PKCE) partner integration, and a hosted Model Context Protocol (MCP) server for connecting AI assistants to restaurant data.

This llms.txt was generated by the API Evangelist enrichment pipeline from Tenzo's public developer portal and the artifacts in this repository. Method: generated (no first-party /llms.txt is published).

## APIs

- [Tenzo API](https://support.gotenzo.com/developers/api-reference/): Public REST API, base URL https://api.gotenzo.com/public/v1/. Read access to locations, areas, sales, and forecast data secured with OAuth 2.0 Bearer tokens.

## Authentication

- [Auth Flow (OAuth 2.0 Authorization Code + PKCE)](https://support.gotenzo.com/developers/auth-flow/): Authorize at https://auth.gotenzo.com/o/authorize, exchange at https://auth.gotenzo.com/o/token/, revoke at https://auth.gotenzo.com/o/revoke_token/. Access tokens live 10 hours; refresh tokens do not expire. Send tokens as `Authorization: Bearer` or `X-AUTH-TOKEN`. Applications are provisioned by Tenzo (partnerships@gotenzo.com).
- Scopes: tenzo/sales:read, tenzo/forecast:read, tenzo/area:read, tenzo/location:read (all read-only).

## MCP

- [Tenzo MCP Server](https://support.gotenzo.com/developers/mcp-server/): Hosted at https://ai.gotenzo.com/mcp (HTTP transport, OAuth). Read-only tools: query_metrics, list_reviews, list_logs, plus helper tools get_analytics_context, get_available_metrics, get_available_dimensions, get_available_filters. Clients: Claude, ChatGPT, Gemini CLI/Enterprise.
